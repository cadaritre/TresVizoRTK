# Identidad visual de TresVizo

El propietario solicitó utilizar la identidad de su empresa, obtenida de [tresvizo.com](https://www.tresvizo.com/).

- `tresvizo-logo.png`: logo original del sitio, descargado sin modificar, 990 × 444 px. [Archivo fuente de Wix](https://static.wixstatic.com/media/b699f8_1af60a19f2b94883a9c59e91a1d10241~mv2.png).
- Fecha de consulta: 19 de septiembre de 2026.
- Colores extraídos de las variables del sitio: `#281a39` (color 15), `#bde9fb` (color 12), `#f6f6f6` (color 11). El azul de acción se adapta al encabezado azul observado del sitio; el azul del logo se conserva en el archivo original.
- Tipografía: el sitio usa Avenir y DIN. El panel emplea fuentes del sistema con Avenir como primera opción; no se redistribuyen archivos de fuentes.
- El dibujo del receptor es un esquema conceptual en CSS, no un modelo mecánico validado.

El panel no solicita recursos externos: logo, estilos y lógica se incluyen comprimidos en la flash. La marca conserva su titularidad; incluirla aquí no define una licencia general para el proyecto.
